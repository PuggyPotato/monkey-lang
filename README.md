Monkey Interpreter

This is an interpreter for the Monkey programming language, written from scratch in Go. It handles lexing, parsing, and evaluating, and includes support for variables, first-class functions, closures, arrays, hashes, and a custom built-in print function.

A huge thank you to Thorsten Ball and his book, Writing An Interpreter In Go. I learned an incredible amount about language design, interpreters, and Go from his work. This project was a fantastic learning experience!

To start the REPL, simply run: go run main.go
